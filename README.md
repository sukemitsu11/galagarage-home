# Galagarage home

Адаптивный концепт сайта бутика домашнего декора в Омске, подготовленный с учётом его ассортимента и предметной фотографии. Крупные изображения и открытая сетка развивают дизайн-референс Case Furniture; содержание относится к Galagarage home.

## Просмотр

Откройте `index.html` в браузере — все фотографии и шрифт находятся в проекте. Для локального HTTP-просмотра нужен Node.js 18 или новее:

```sh
git clone https://github.com/sukemitsu11/galagarage-home.git
cd galagarage-home
npm start
```

Адрес: http://127.0.0.1:4173. Зависимости не требуются. Для другого порта задайте переменную окружения `PORT`.

Проверка синтаксиса:

```sh
npm run check
```

Проект — статические HTML/CSS/JS. Для статического хостинга публикуется корень, команда сборки не нужна. Скрипт `server.cjs` служит только локальному просмотру и слушает 127.0.0.1.

## Возможности

- 12 предметов: вазы и декор, посуда, текстиль, мебель и свет.
- Фильтрация по категории, раскрытие всей коллекции, сортировка по цене.
- Подборка подарков до 2 000, 5 000 и 10 000 ₽, сброс бюджета.
- Поиск по названию, категории и ключевым словам; состояние пустой выдачи.
- Карточки с фотографиями, характеристиками, вариантами и ссылкой на публикацию.
- Для вазы Mushroom и стола-конуса выбор варианта меняет показанную цену.
- Избранное в localStorage с резервным хранением в памяти.
- Адаптивное меню, управление с клавиатуры, reduced motion.
- Кнопка уточнения наличия открывает WhatsApp с названием предмета, выбранным вариантом и ссылкой на источник. Сообщение автоматически не отправляется.

## Структура

- `index.html` — содержание страницы, контакты и диалоги.
- `catalog.js` — состав коллекции, цены, варианты, характеристики и ссылки на посты.
- `app.js` — фильтрация, поиск, галерея, избранное и навигация.
- `styles.css` — адаптивный дизайн.
- `assets/` — фотографии, локальный шрифт Onest и OFL-лицензия.
- `SOURCES.json` — происхождение каждого изображения.
- `RESEARCH.md`, `DESIGN.md` — исследование и визуальные решения.
- `QA.md`, `DESLOP.md` — выполненные проверки и итоговый редакторский проход.

Изменения каталога вносятся в `catalog.js`. После замены фотографий обновите `SOURCES.json`. На GitHub отправляется исходный код; отдельный сайт автоматически не развёртывается.
