# Galagarage home

Сайт бутика домашнего декора в Омске: каталог, корзина с заказом через WhatsApp и Telegram, админка для владельцев. Крупные фотографии и открытая сетка каталога развивают дизайн-референс (dzadza.ru), содержание относится к Galagarage home.

## Запуск

Один `docker-compose.yml` поднимает три сервиса:

- `db`: Postgres 17;
- `backend`: API на Go (образ `<логин>/galagarage-backend`);
- `frontend`: nginx со сборкой React, проксирует `/api` и `/uploads` в backend (образ `<логин>/galagarage-frontend`). Это единственный сервис с открытым портом.

```sh
cp .env.example .env      # ADMIN_PASSWORD (от 12 символов), DB_PASSWORD, DOCKERHUB_USER
docker compose up -d
```

Сайт: http://127.0.0.1:8080, админка: http://127.0.0.1:8080/admin. Если образов с вашим `DOCKERHUB_USER` ещё нет в Docker Hub, соберите их локально: `docker compose build`.

Пароль `DB_PASSWORD` применяется при первом создании тома `pgdata`. Чтобы сменить его позже, выполните `docker compose down -v` (удалит данные) или `ALTER USER` в psql.

### Публикация образов в Docker Hub

```sh
docker login
docker compose build
docker compose push backend frontend
```

Образы называются `$DOCKERHUB_USER/galagarage-backend:$TAG` и `$DOCKERHUB_USER/galagarage-frontend:$TAG` (по умолчанию тег `latest`). На сервере достаточно `docker-compose.yml` и `.env` (`DOCKERHUB_USER` обязателен, иначе compose не стартует):

```sh
docker compose pull && docker compose up -d
```

Если собираете на Mac с Apple Silicon для сервера на amd64, добавьте `--platform linux/amd64` через `DOCKER_DEFAULT_PLATFORM=linux/amd64`.

### Разработка

Postgres в Docker, API на Go и Vite локально:

```sh
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d db
cd server && DATABASE_URL="postgres://galagarage:<DB_PASSWORD>@127.0.0.1:5432/galagarage?sslmode=disable" ADMIN_PASSWORD=dev-password-123 UPLOAD_DIR=./uploads go run .
npm install && npm start
```

Адрес: http://127.0.0.1:4173 (Vite проксирует `/api` и `/uploads` на порт 8080).

Проверка сборки: `npm run build` и `cd server && go vet ./...`.

## Устройство

- Каталог хранится в Postgres (таблица `products`). Фото загружаются через админку в том `uploads` и отдаются по `/uploads/...`.
- Админка `/admin` — отдельная страница без шапки и подвала сайта. Вход по одному общему паролю из `ADMIN_PASSWORD`, сессия 12 часов в HttpOnly-cookie, пять попыток входа за 10 минут. Вкладки:
  - «Товары»: поиск, фильтр по разделу и видимости, добавить, изменить, скрыть или показать, удалить. Фото можно загружать пачкой, менять порядок и выбирать главное.
  - «Разделы»: добавить, переименовать, сменить фото, поменять порядок, удалить пустой раздел. Раздел с товарами удалить нельзя.
  - «Настройки»: телефон, WhatsApp, Telegram, канал, адрес, часы, ссылка 2ГИС, заголовок, текст и три фото баннера на главной.
- Разделы хранятся в таблице `categories`, настройки сайта в таблице `settings`. Обе создаются и заполняются при первом запуске.
- У товара: название, раздел, цена, цвет, высота, ширина и длина (см), описание, список характеристик, фотографии.
- При первом запуске создаются три демонстрационных товара. Отключить: `SEED_DEMO=false`.
- Корзина и избранное хранятся в браузере (`localStorage`, без срока действия). Избранное остаётся, пока посетитель его не очистит или не удалит данные сайта.
- Кнопки WhatsApp (`wa.me/<номер>?text=`) и Telegram (`t.me/+<номер>?text=`) открывают чат бутика с готовым текстом заказа. Ссылка Telegram по номеру работает, только если в настройках приватности владельца разрешено находить его по номеру телефона.
- nginx передаёт backend реальный адрес клиента, поэтому лимит попыток входа считается по клиентам. Внешний прокси на том же сервере (Caddy, nginx) должен слать `X-Forwarded-For`, nginx в compose ему доверяет (`set_real_ip_from 172.28.0.1` в `deploy/nginx.conf`). Для Cloudflare или прокси на другом адресе измените эту строку, иначе все клиенты будут для лимита одним адресом и вход можно заблокировать пятью неверными паролями. Не открывайте порт на `0.0.0.0` без прокси перед ним.
- По https обязательно задайте `SECURE_COOKIES=true`, иначе cookie админки уйдёт по http. Смена `ADMIN_PASSWORD` завершает все сессии. HSTS добавляйте на внешнем прокси, который завершает TLS.
- Фотографии сохраняются как загружены, вместе с EXIF (в том числе GPS). Перед загрузкой лучше убрать метаданные.

## Структура

- `server/`: API на Go (gin, pgx): `main.go`, `auth.go`, `handlers.go`, `db.go`, `config.go`.
- `src/`: React. `pages/` (главная, каталог, товар, админка), `components/` (шапка, подвал, корзина, плитка), `store.jsx` (каталог и корзина), `api.js`.
- `public/assets/`: фотографии бутика, шрифт Onest и OFL-лицензия.
- `docker-compose.yml`, `docker-compose.dev.yml`, `server/Dockerfile`, `Dockerfile.frontend`, `deploy/` (nginx), `.env.example`: запуск.
- `RESEARCH.md`, `DESIGN.md`, `QA.md`, `DESLOP.md`: материалы первой версии концепта.
